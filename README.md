# HyLab BioPolicy Platform v2.0

Technology, Policy, Industry, Regulation을 동일한 탐색 구조로 구현한 GitHub Pages용 정적 웹사이트입니다.

## 실행
`index.html`을 열거나 GitHub Pages에 전체 폴더를 업로드합니다.

## 추가된 기능
- Policy 5개 영역 및 하위 주제 탐색
- Industry 4개 영역 및 하위 주제 탐색
- Regulation 3개 영역 및 하위 주제 탐색
- 공통 Overview, Areas, Key Statistics, Featured Reports, Resources, HyLab Reports, Research Notes
- URL 쿼리 기반 직접 접근 및 뒤로가기 지원
