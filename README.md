# BioPolicy Intelligence Platform v1.4

## v1.4 변경사항
- v1.3 구조를 기반으로 **기술(Technology) 파트만 논의 결과에 맞게 개편**
- 기술주제 4개를 좌측 메뉴가 아닌 **상단 탭**으로 배치
  - 합성생물학
  - AI 바이오
  - 신약개발
  - 그린·화이트바이오
- 기술 메인 화면 구성 확정
  1. 기술 배너
  2. 상단 기술주제
  3. 기술 분야 개요
  4. 바이오 일반 핵심지표
  5. AI 정책질문
  6. 선택 기술주제 상세
- `핵심지표`는 개별 기술지표가 아니라 **바이오 일반 지표**로 반영
- `주요 정책 질문` 명칭을 **AI 정책질문**으로 변경
- 개별 기술주제 상세 구성
  1. 한줄 정의
  2. 정책 아젠다
  3. 핵심기술
  4. 국내외 동향(기술·정책·산업·제도)
  5. 관련자료
- 정책 아젠다는 단순 이슈가 아니라 **현재 수행 중이거나 향후 추진할 정책업무**로 표현
- 정책·산업·제도 파트는 v1.3 구조 유지

## 실행
브라우저 보안정책상 JSON 로딩을 위해 로컬 서버에서 실행하세요.

```bash
cd biopolicy-platform-v1.4
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 주요 파일
- `index.html`: 화면 구조
- `assets/css/style.css`: 전체 디자인 및 v1.4 기술파트 스타일
- `assets/js/app.js`: 화면 전환과 기술주제 인터랙션
- `data/dashboard.json`: 지표, AI 정책질문, 정책 아젠다, 기술주제 데이터
