# BioPolicy Intelligence Platform v1

기술 → 정책 → 산업 → 제도를 연결하는 GitHub Pages용 정적 대시보드입니다.

## 파일 구조

- `index.html`
- `assets/css/style.css`
- `assets/js/app.js`
- `data/dashboard.json`

## GitHub 업로드

1. ZIP 압축을 풉니다.
2. 압축을 푼 폴더 안의 `index.html`, `assets`, `data`, `README.md`를 저장소 최상위에 업로드합니다.
3. GitHub Pages 설정이 `Deploy from a branch / main / root`인지 확인합니다.
4. 배포 후 1~3분 뒤 페이지를 새로고침합니다.

## 주의

현재 수치는 UI 검증용 예시입니다. 다음 단계에서 엑셀 원자료와 공식 API 데이터로 교체해야 합니다.
